# The Missing Rainbow Acorn

En illustrert bildebokfilm basert på manuset til Sunny Meadow Friends.

- Lengde: 4 minutter og 13 sekunder.
- Format: MP4, 1280 × 720, H.264-video og AAC-lyd.
- 14 scener med stillbilder og rolige kamerabevegelser.
- Engelsk syntetisk fortellerstemme, engelske undertekster og egenlaget syntetisk bakgrunnsmusikk.
- KI-genererte illustrasjoner; enkelte figurdetaljer kan variere mellom scenene.

## Last ned filmen

Åpne `The-Missing-Rainbow-Acorn.mp4` og velg nedlastingsikonet (Download raw file). GitHub viser ikke nødvendigvis en videospiller. Åpne den nedlastede filen i QuickTime Player eller en annen videospiller.

`thumbnail.jpg` er miniatyrbildet. `subtitles.srt` inneholder separate engelske undertekster; filmen har også innbrente undertekster.
